# Сонный радиоприёмник v1.3.0

## Что нового
- Караоке-текст при озвучке
- Умный таймер: до конца главы / фразы; fade голоса и ambient
- Автостоп на конце главы или автопереход к следующей
- Раздельная громкость голоса и ambient в плеере
- Предпрослушивание голоса в настройках
- Голос Денис (Piper) по умолчанию; смена голоса на лету
- RSS со своими лентами, continue для URL/новостей
- Пресеты Piper, Android-виджет

## Установка
Скачайте `SleepingRadio-v1.3.0.apk` из Assets и установите (разрешите установку из неизвестных источников при необходимости).

Offline-модели голосов качаются из приложения при выборе голоса.
