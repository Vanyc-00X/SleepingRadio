# Этапы разработки — «Сонный радиоприёмник»

Стек: **Flutter** (Android first) · Drift/SQLite · `just_audio` + `audio_service` · облачный TTS/LLM с заделом под локальные модели.

---

## Этап 0 — Фундамент ✅

**Цель:** рабочий каркас приложения без бизнес-логики плеера и ИИ.

- [x] Инициализация Flutter (Android + iOS)
- [x] Слоистая структура (`core` / `domain` / `data` / `features`)
- [x] Тёмная «ночная» тема, типографика
- [x] Навигация: Home · Библиотека · Now Playing · Настройки
- [x] Модели данных по ТЗ (§9)
- [x] Локальная БД (Drift) + репозиторий настроек
- [x] Документ этапов

**Критерий готовности:** приложение запускается, шелл кликабелен, настройки сохраняются локально.

---

## Этап 1 — Плеер и таймер сна ✅

**Цель:** сценарий «слушать что угодно + заснуть».

- [x] Фоновый `AudioService` / Lock Screen / кнопки гарнитуры
- [x] Play / Pause / Seek ±15 с
- [x] Таймер: 15/30/45/60/90 + своё значение + «до конца»
- [x] Плавный fade-out 45 с (в окне 30–60), продление +15 мин
- [x] Экран Now Playing (ночной режим, крупный Play/Pause)
- [x] Демо-трек `assets/audio/night_loop.wav` (loop) + сохранение позиции

**Критерий:** ≥30 мин фонового воспроизведения тестового аудио с таймером и сохранением позиции.

---

## Этап 2 — Книги ✅

**Цель:** сценарий A из ТЗ.

- [x] Импорт `.fb2` / `.epub` (file picker)
- [x] Парсинг оглавления, навигация по главам
- [x] Прогресс (книга / глава / символьная позиция)
- [x] Скорость 0.8×–1.5× (из настроек), режим «Только чтение»
- [x] Вкладка «Книги» в библиотеке + экран книги
- [x] Озвучка главы системным TTS в фоне (облачные голоса — этап 3)

**Критерий:** импорт → выбор главы → фон + таймер → прогресс сохраняется.

---

## Этап 3 — TTS (озвучка) ✅

**Цель:** спокойный голос для текста.

- [x] 2 голоса (облачный neural TTS OpenAI-compatible + системные профили)
- [x] Чанкование текста, дисковый кэш аудио с лимитом ГБ
- [x] Настройки: голос, скорость, высота тона, API key
- [x] Экран «Что уходит в сеть»
- [x] Fallback: системный TTS при выключенном облаке / ошибке / отсутствии ключа

**Критерий:** короткий текст (~5k знаков) озвучивается ≤60 с на среднем устройстве/сети.

---

## Этап 4 — URL Reader ✅

**Цель:** сценарий C.

- [x] Ввод URL + (задел) share-target / query `?url=`
- [x] Reader-mode извлечение текста + понятные ошибки
- [x] Режимы: Прочитать / + комментарий / Краткий пересказ + комментарий
- [x] Локальный CalmScriptComposer (комментарий — отдельный блок)
- [x] Сохранение в библиотеку (вкладка «Ссылки») + озвучка через TTS

**Критерий:** публичная статья извлекается и озвучивается; комментарий — отдельный блок.

---

## Этап 5 — Новости ✅

**Цель:** сценарий B.

- [x] Публичные RSS (BBC / NASA / HN и др. по темам)

- [x] Пайплайн: сбор → факты → комментарий → TTS

**Цель:** закрыть критерии приёмки §12.
