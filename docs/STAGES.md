# Этапы разработки — «Сонный радиоприёмник»

Стек: **Flutter** (Android first) · Drift/SQLite · `just_audio` + `audio_service` · облачный TTS/LLM с заделом под локальные модели.

---

## Этап 0 — Фундамент *(текущий)*

**Цель:** рабочий каркас приложения без бизнес-логики плеера и ИИ.

- [x] Инициализация Flutter (Android + iOS)
- [x] Слоистая структура (`core` / `domain` / `data` / `features`)
- [x] Тёмная «ночная» тема, типографика
- [x] Навигация: Home · Библиотека · Now Playing · Настройки
- [x] Модели данных по ТЗ (§9)
- [x] Локальная БД (Drift) + репозиторий настроек
- [x] Документ этапов

**Критерий готовности:** приложение запускается, шелл кликабелен, настройки сохраняются локально.

---

## Этап 1 — Плеер и таймер сна

**Цель:** сценарий «слушать что угодно + заснуть».

- Фоновый `AudioService` / Lock Screen / кнопки гарнитуры
- Play / Pause / Seek ±15 с
- Таймер: 15/30/45/60/90 + своё значение + «до конца главы»
- Плавный fade-out 30–60 с, продление +15 мин
- Экран Now Playing (ночной режим, крупный Play/Pause)

**Критерий:** ≥30 мин фонового воспроизведения тестового аудио с таймером и сохранением позиции.

---

## Этап 2 — Книги

**Цель:** сценарий A из ТЗ.

- Импорт `.fb2` / `.epub` (share / file picker)
- Парсинг оглавления, навигация по главам
- Прогресс (книга / глава / позиция)
- Скорость 0.8×–1.5×, режим «Только чтение»
- Вкладка «Книги» в библиотеке

**Критерий:** импорт → выбор главы → фон + таймер → прогресс сохраняется.

---

## Этап 3 — TTS (озвучка)

**Цель:** спокойный голос для текста.

- 2 голоса (облачный neural TTS)
- Чанкование текста, кэш аудио
- Настройки: голос, скорость, (высота при поддержке)
- Экран «Что уходит в сеть»
- Fallback: системный/локальный TTS

**Критерий:** короткий текст (~5k знаков) озвучивается ≤60 с на среднем устройстве/сети.

---

## Этап 4 — URL Reader

**Цель:** сценарий C.

- Ввод URL + (задел) share-target
- Reader-mode извлечение текста + понятные ошибки
- Режимы: Прочитать / + комментарий / Краткий пересказ + комментарий
- Сохранение в библиотеку (вкладка «Ссылки»)

**Критерий:** публичная статья извлекается и озвучивается; комментарий — отдельный блок.

---

## Этап 5 — Новости

**Цель:** сценарий B.

- 1–2 RSS/API источника
- Фильтры тем (MVP-набор)
- Пайплайн: сбор → факты → комментарий → TTS
- Дисклеймер, «Только факты» / «Без комментариев»
- Лента + «Сформировать выпуск»

**Критерий:** выпуск «сводка + комментарий» формируется и играет.

---

## Этап 6 — Библиотека, онбординг, полировка MVP

**Цель:** закрыть критерии приёмки §12.

- Вкладки: Книги / Выпуски / Ссылки / Избранное
- История прослушиваний, удаление/переименование
- Онбординг ≤3 экрана, выбор предпочтений и голоса
- Обработка ошибок человеческим языком
- Accessibility: крупные кнопки, базовая TalkBack

**Критерий:** все 7 пунктов §12 ТЗ выполнены.
