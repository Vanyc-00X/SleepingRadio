# Сонный радиоприёмник v1.2.0

Ночное аудиоприложение: книги, новости, ссылки и спокойные выпуски с таймером сна.

## Что нового
- Мини-плеер и более спокойный интерфейс
- URL Reader и раздел новостей
- Конструктор вечерних выпусков
- Импорт txt/pdf, Share из Android
- Offline TTS, ambient-подложка, опциональный Ollama
- Рекомендации тем и локальный бэкап настроек

## Запуск
```bash
flutter pub get
flutter run
```

Android first. Облачный TTS: ключ в Настройках или `--dart-define=TTS_API_KEY=...`
